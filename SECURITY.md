# Política de seguridad de Noditos

## Versiones soportadas

Noditos se encuentra en beta. Sólo la beta más reciente recibe correcciones; no existe todavía un SLA público. No uses builds antiguas ni la beta con información sensible.

## Reportar una vulnerabilidad

No publiques secretos, claves API, datos personales ni detalles de una vulnerabilidad explotable en una issue pública.

Usá el canal privado **Report a vulnerability** de GitHub:

https://github.com/Guallama31/Noditosv1/security/advisories/new

Incluí, cuando sea posible:

- versión/build y sistema operativo;
- pasos mínimos para reproducir;
- impacto esperado;
- evidencia sin datos reales de terceros;
- mitigación sugerida;
- si existe explotación activa.

## Proceso

El proyecto intentará confirmar recepción y clasificar el reporte. Los tiempos formales de respuesta se definirán antes de la versión estable. Se coordinará la divulgación después de disponer de una corrección o mitigación. No se garantiza recompensa económica.

## Alcance autorizado

Se acepta investigación de buena fe sobre copias propias de Noditos que evite:

- acceder o alterar datos de otras personas;
- degradar servicios de terceros;
- ingeniería social;
- publicación prematura de detalles explotables;
- uso de claves o cuentas que no pertenezcan al investigador.

Este texto no constituye autorización para infringir leyes ni condiciones de terceros.
